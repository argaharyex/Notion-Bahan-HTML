Analogi Jaringan Komputer Interaktif

1 Default Gateway & Traffic Pintu Keluar

Pintu Gerbang Kompleks

Anda bebas bermain atau berkendara di dalam kompleks rumah sendiri tanpa izin. Namun, untuk pergi ke jalan raya utama kota, Anda wajib melewati satu-satunya pintu gerbang utama.

Kotak Surat Pos Satpam

Surat ke tetangga kompleks diantar sendiri (Lokal). Jika untuk luar kota, Anda masukkan ke kotak pos satpam (Default Gateway) untuk diproses ekspedisi luar.

Konsep Jaringan

Local Traffic: Langsung via Switch (MAC).
Remote Traffic: Dikirim ke router IP (Default Gateway 192.168.1.1) untuk keluar subnet.

Status: Siap. Pilih simulasi di pojok kanan atas. Pintu Gerbang & Gateway

Loket Gerbang Tol (ARP)

Tahu KM tujuan (IP Address), tapi tidak tahu nomor loket fisik yang aktif. Supir mengumumkan broadcast (ARP Request), loket balaskan MAC Address-nya.

Nomor Apartemen (Port)

Gedung apartemen punya 1 IP tunggal. Di dalamnya terdapat nomor kamar (Port) khusus untuk tiap aplikasi agar data masuk ke tujuan yang tepat dan tidak tertukar.

Fungsi Port Layanan

Port 80: Web HTTP Biasa.
Port 443: Web HTTPS Aman (SSL).
Port 22: Remote Server (SSH Terminal).

Status: Pilih aksi untuk menyimulasikan ARP Broadcast atau Pengiriman ke Port. ARP & Multiplexing Port

Kontak HP & Buku Saku

Tidak perlu hafal angka IP, cukup cari nama domain. Cache lokal menyimpan query sebelumnya agar tak tanya ulang.

Format Alamat Hierarki

Alur dibaca dari cakupan terbesar ke spesifik: Negara (.id) $\rightarrow$ Provinsi (co) $\rightarrow$ Jalan/Domain (google).

Resepsionis Mal (Iteratif)

Resepsionis (Root) mengarahkan ke Satpam Lantai (TLD), lalu tiba di Toko Otoritatif penyedia data.

Label Warna (Record Types)

Merah: IPv4 (A), Biru: IPv6 (AAAA), Kuning: Alias (CNAME).

Status: Klik "Jalankan Query DNS Iteratif" untuk melihat alur pencarian hierarki domain. Resolusi DNS Rekursif/Iteratif

Aplikasi Maps & Papan Petunjuk

Router membaca tabel routing layaknya papan instruksi di persimpangan jalan untuk memilih rute tercepat berdasarkan jarak & beban.

Static Routing (Jalur Busway/Kereta)

Jalur dipatok permanen secara manual. Jika di depan ada hambatan / perbaikan jalan, kendaraan tidak bisa berbelok mencari jalan alternatif.

Dynamic Routing (Sopir Taksi Lihai)

Sopir bertukar informasi lalu lintas real-time. Begitu detect rute macet/putus, otomatis mengalihkan rute lewat jalan tikus secara mandiri.

Status: Kondisi Jalan Normal. Klik "Jalankan Mobil" atau coba tombol "Buat Hambatan". Static vs Dynamic Routing

Sintesis Rantai Pengiriman Data (End-to-End Flow)

Integrasi Seluruh Analogi: Pengemasan Kardus PDU --> Pencarian DNS --> Switching Lokal --> Gateway/ARP --> Routing Ekspedisi --> Delivery Port Tujuan.

Status: Siap memulai rute data end-to-end. Klik tombol simulasi di atas. End-to-End Data Journey
